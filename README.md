# 🧠 Disease Prediction App (Flask + ML)

A web-based machine learning project built using **Flask** to predict diseases based on symptoms provided by the user.

## 🚀 Features
- Predicts possible diseases from user input symptoms
- Trained with ML model using datasets like XYZ
- Simple and interactive web interface

## 🛠️ Tech Stack
- Python
- Flask
- Scikit-learn
- HTML/CSS
- joblib (for model loading)
